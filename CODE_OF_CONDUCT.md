# Contributor Covenant Code of Conduct (summary)

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which is incorporated here by reference.

## Our standard

Be respectful and constructive. Welcome newcomers, assume good intent, give and accept feedback gracefully,
and focus on what is best for the project and its users. Unacceptable behaviour includes harassment,
discrimination, personal attacks, trolling, publishing others' private information, and anything that would be
inappropriate in a professional setting.

## Scope and enforcement

This applies to all project spaces (issues, pull requests, discussions) and to people representing the project
in public. Maintainers may remove, edit or reject contributions that violate this code and may ban repeat
offenders. Report concerns privately through GitHub's "Report abuse" on the content or by contacting the
maintainers via the repository's Security tab. Reports are handled confidentially.
